path = "why-i-build-software"

I build software because I'm passionate about solving problems that have an
impact in the community. I like treating every problem as a puzzle to be solved,
and I find joy in optimizing a solution — whether it's a traditional approach or
a novel workaround. Making tradeoffs, not only in performance but in the time
needed to implement a solution, and weighing higher-level factors such as the
frameworks and tech stack used, are interesting parts of any solution that I
enjoy pondering when building a new system or updating an existing one.
